깨알람 개인정보처리방침

시행일: 2026년 9월 14일 · 이전 버전: 2026년 8월 24일

깨알람(이하 "앱")은 회원가입과 로그인이 없고, 이름·이메일·전화번호를 받지 않습니다. 다만 앱을 고치고 알람이 제대로 울리는지 확인하기 위해 아래 정보를 자동으로 보냅니다. 무엇을, 왜, 어디로 보내는지 그대로 적었습니다.

1. 기기 안에만 저장하는 정보

  • 알람 설정, 학습 진도, 오답·복습 기록, 앱 설정
  • 이용자가 직접 '백업 내보내기'를 할 때만 파일로 만들어지며, 그 파일을 어디에 두는지는 이용자가 정합니다.

2. 자동으로 보내는 정보와 목적

  • 사용 기록 — 앱 실행과 화면 이동, 학습·퀴즈 결과(단어, 정답 여부, 응답 시간), 알람 예약·발동 정보(시각, 요일, 알람음), 설정 변경, 알림 권한 허용 여부, 앱 오류 기록
  • 기기·앱 정보 — 기기 모델과 제조사, 운영체제 버전, 화면 크기, 기기 언어, 앱 버전
  • 식별 코드 — 설치할 때마다 새로 만드는 무작위 코드. 광고 ID나 기기 고유번호가 아니며, 앱을 지우고 다시 설치하면 바뀝니다.
  • 접속 정보 — 전송할 때의 IP 주소와, 그로부터 추정한 대략적 위치(국가·도시)
  • 비정상 종료 진단 정보 — 앱이 오류로 종료될 때 오류 내용, 기기 종류, 운영체제 버전. 개인 식별 정보 수집 옵션은 꺼져 있습니다.

목적: 오류 수정, 알람이 제때 울리는지 확인, 기능 개선을 위한 통계. 광고·마케팅에 쓰지 않고, 다른 앱·웹사이트와 연결해 이용자를 추적하지 않습니다.

3. 이용자가 직접 보낼 때만 받는 정보

  • 오류 신고 — 고른 증상, 직접 적은 내용, 위 2의 기기·앱 정보. 적는 칸에는 개인정보를 넣지 말아 주세요.
  • 이메일 문의 — 보내신 이메일 주소와 내용, 메일에 자동으로 채워진 설치 코드·기기 정보. 답장과 문제 확인에만 씁니다.

5. 보관 기간과 파기

  • 기기 안의 정보는 앱을 지우거나 '전체 초기화'를 하면 삭제됩니다.
  • 전송된 사용 기록·진단 정보는 각 업체의 보존 정책에 따라 보관되고, 목적을 이루었거나 삭제를 요청하면 지체 없이 삭제합니다.
  • 이메일 문의는 처리가 끝난 뒤 필요한 기간만 보관합니다.

6. 이용자의 권리

  • 자신의 정보에 대해 열람·정정·삭제·처리 정지를 요청할 수 있습니다.
  • 앱의 설정 → 고객지원 → '이메일로 문의'를 쓰면 설치 코드가 함께 전달되어 해당 데이터를 찾을 수 있습니다. 요청은 지체 없이 처리합니다.

  • 분석 도구와 오류 수집 도구는 개발자 계정으로만 접근할 수 있습니다.
